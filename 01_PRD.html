自选分镜版本与一键出片

“03 批量制作”的每个镜头都有“选择分镜版本”，可看图比较并选用；不调用模型。已选版本优先于最新候选，不会因重做图片而自动替换。一键确认窗口也可逐镜换版本、使用自定义图或选择重新生成，并实时计算图片和视频请求数。视频的手动选择与自动采用均可使用；缺片窗口增加“自己选择视频版本”，批量采用只是快捷选项。

当前短剧提供两条路径。在“03 批量制作”点击“一键出片”，确认各镜头使用的分镜版本及调用数量后，复用已选图片、仅补生成缺失图片，并制作视频。默认自动采用并合成当前集预览，也可选择“保留为候选，我自己选择视频版本”。全部剧集的片段均保留，可逐集预览或批量导出。需要控制画面时，使用“仅制作分镜图 → 检查 / 确认分镜 → 用确认分镜生成视频 → 视频版本采用”的逐步路径。单镜头返修仍不自动覆盖已选版本。

一键结果标记为自动初稿，未经过人工质量审核。该入口不会自动重新拆分故事或替换当前分镜表。复用已有分镜时直接固化该图作为视频输入，不创建图片任务；新增分镜与视频按后端 depends_on 关联，视频使用本批次图片结果；已提交任务在后端持久保存。恢复页面只查询，不自动补发或重提模型请求。生成期间的编辑冲突会保留结果、阻止自动覆盖；失败、未知提交、取消时下游等待并显示异常，需要用户核查。

合成使用浏览器本地编码，需保持页面打开并位于前台。预览失败保留原片段，不自动重复编码；用户可再次点击预览。全部提交前关闭页面会留下未完整提交状态，必须到任务中心核查。停止本批次会停止本地后续及自动采用，不保证撤回供应商运算或费用。

导出前如果缺片，现在显示具体镜头与匹配情况。已有匹配视频时可批量采用并预览，不调用模型；没有匹配视频时不会将分镜图冒充真实视频，提供制作入口和无调用的已验证案例入口。

增量实测已完成：1张修订图、2段3秒视频，审核、主动采用与成片导出通过本次样例检查；生成质量的结论仅适用于该样例。完整记录见模型评测报告与验收记录。

需求已实现的行为与验收口径
分镜人工确认逐步制作时，每镜进入“检查 / 确认分镜”，选候选图，编辑首帧构图与视频动作，勾选人数、反射、服饰和构图检查，再确认。确认本身不调用模型；不是AI自动质检。
版本有效性确认绑定当前构图描述、角色、角色描述、比例、全片约束及图片版本。相关内容改变后原确认失效，需重新确认；字幕和视频动作可另行修改。
分离图片与视频“仅制作分镜图”不会自动创建视频；逐步制作要求分镜有效确认后提交视频。“一键出片”则自动创建图片及其依赖的视频任务，无需逐镜确认。视频将已确认首帧固化为输入图片，并记录来源素材 ID。
单镜头视频返修“生成此镜视频 / 仅重做视频”只创建该镜头一个视频请求，不再生成图片。同镜头已有执行中视频时阻止重复提交；旧视频保留。
视频版本采用逐步制作与单镜返修的结果为候选。“视频版本”可预览、下载与采用；一键出片可选择自动采用该批次片段，旧版本保留。旧版项目首次载入时沿用其原有最后片段，新生成的候选不会悄然覆盖。
导出真实模式要求各镜头已采用片段，字幕、时长和排序由当前编排决定。缺片或画面/动作描述与所用视频不一致时明确报错，原素材仍可预览下载。
真实参数说明取消没有对应API参数的“成品优先/快速预览”按钮；当前统一模型与尺寸参数，不承诺虚构速度或质量差异。

质量判断仍需人工。复杂倒影、多人物同步与跨镜头连续性没有自动保证；首尾帧API、多参考主体模式、自动质检和专业转场未在本轮实现。原题允许简化交互原型，本轮以可审核、可返修、可导出的双场景闭环为验收目标。

版本边界与原题差异

原测试题要求全部推理在本地完成、无云端兜底。用户后续明确授权升级为百炼真实 API，因此本版采用“本地工作台与后端＋云端模型推理”，上传的商品图、角色图及生成请求会发送至百炼。本版不再满足原题的全本地推理条件；原始本地交互原型可用于展示该约束下的产品设计。具体电脑配置不进入交付文档。

01 / PRODUCT PURPOSE

产品目标与验收对象

Forma 面向个人创作者与小型内容团队，在一个工作台中完成电商素材与批量短剧的生产。以流程引导组织业务对象，以画布和镜头编排完成修改，共用项目、素材、模型配置和任务中心。

本次必须覆盖两个场景，以及多任务并发、中断、失败恢复和草稿保存。API 版进一步把商品方案、脚本分镜、参考图编辑、图生视频接入真实服务，同时保留明确标注的本地模板合成和静帧运镜模式。

电商用户任务

上传任意商品的多个 SKU 原图，批量制作主图、生活场景图和不同尺寸素材，挑选、编辑、重做并导出。

保温杯为预置案例。三个颜色的小花瓶等新商品也必须使用用户上传的对应图片，不得回退到案例素材。

短剧用户任务

输入故事，建立角色参考，生成可编辑的分镜；一键生成分镜图与视频初稿，或人工确认分镜图后再生成视频片段，调整编排并导出可播放结果。

《未发送的消息》为预置案例；预置图像不代表真实生成成功，也不证明跨镜头一致性已经达到生产标准。

本文按当前 server.py、forma/api.js、app.js 定义 API 版需求和交付边界。本次已完成真实文本、图片、视频的单次端到端联调，以及真实视频片段的分集录制；这些证据说明链路可用，不代表批量成功率、生成质量或生产稳定性已经达标。详细结果以模型评测报告与最终验收记录为准。

02 / WORKFLOW & MODULES

模块协作与双场景流程

商品 / 故事与参考图→AI 方案预览→用户应用与修改→批量任务快照→结果编辑与导出
模块输入、输出与解决的问题协作规则
项目与素材保存商品、SKU、脚本、角色、分镜、上传图片、结果版本和编辑草稿，避免素材与业务对象脱节。使用项目 ID、SKU / 角色 / 分镜 ID 关联；归档项目的任务仍回到原项目。前端草稿与后端任务分别持久化。
方案与分镜助手DeepSeek 经百炼生成商品文案或结构化分镜；减少从空白开始整理和重复输入。校验字段、角色引用和镜头时长等结构；先展示候选，再由用户应用。分镜字幕允许为空，标题与画面描述必须非空；模型输出不构成真实卖点依据。
图片制作与画布wan2.6-image 以商品图或角色图为参考执行真实编辑；本地模板模式提供原图排版。画布负责文字、布局与尺寸。参考图与提示词进入任务快照。AI 图可能改变商品属性，结果需人工检查；模板保留原图背景，不宣称自动抠图。
短剧与视频管理分集、分镜、参考角色、字幕、时长和排序；wan3.0-video 以分镜图生成片段，异步查询结果。逐步制作绑定人工确认的图片版本；一键出片使用本批次图片任务的完成结果作为视频首帧，后端按依赖调度。重做分镜不替换已有片段。静帧运镜另行标注。
API 与模型显示后端连接、密钥是否配置、模型 ID 和连通性信息，解决模拟状态被误认为服务可用的问题。密钥仅后端内存或私有 .env；前端不回显完整密钥，不写入 IndexedDB、备份、日志。未配置时阻止真实请求。
后端任务中心持久队列接收请求、调度与轮询、保存远端任务 ID、缓存结果；页面关闭后仍可跟踪执行。最多 2 项同时执行，其中图片最多 1 项、视频最多 1 项；文本等任务服从总并发限制。真实任务状态与本地演示分开。

电商流程

商品与素材 → 可选“AI生成商品方案” → 预览并应用 → 场景、尺寸与生成模式 → 批量制作 → 单张检查与画布编辑 → PNG / ZIP / 项目备份。生成数量按 SKU × 场景 × 尺寸显示，提交前说明使用云端还是本地模板。

短剧流程

故事与角色 → “AI拆分分镜”或明确标注的本地规则拆分 → 预览并应用 → 逐镜调整 → 分镜图制作 → 绑定完成图片生成视频 → 编排、字幕与预览 → 片段 / 分集输出与分镜包。不能将分镜缩略图的存在等同于生成视频完成。

F05 画布编辑调整商品位置、缩放、裁切、文案、配色及尺寸；保存为新版本。原图和原结果保留；API 成图作为整图进入画布与导出，支持整体布局、裁切和文字，不承诺把商品自动拆成独立图层。
F06 AI 分镜DeepSeek 从故事生成分集与分镜结构，角色引用校验；允许编辑画面描述、时长、字幕和角色。候选先预览；应用前检查输入修订号。输入已改动则提示冲突，用户检查后可明确确认覆盖；未确认不覆盖。分镜替换前保留旧分镜版本。原项目未加载时仅下载方案 JSON，不套用当前其他项目。

F08 编排与导出修改镜头顺序、字幕与时长，预览、导出片段和分镜包；保留本地静帧分集导出。真实 API 模式要求各镜头已有真实片段，按顺序播放并录制、叠加当前字幕；本地模式另用静帧运镜。实测 16:9 分集输出 WebM / VP9、960×540、无音轨；不承诺无损拼接、音频保留或专业剪辑。
F09 持久任务与并发后端执行真实请求；总并发 2、图片 1、视频 1；显示依赖、真实状态和队列顺序。相同任务 ID 和相同输入重复到达后端时返回已有记录，输入不同则拒绝；新的任务 ID 属于新调用，连续主动新建文本请求不能视为自动去重。页面刷新不启动第二份远端任务。无实际进度时展示阶段而非伪造百分比。
F10 局部恢复失败仅处理该任务；已完成成果不丢失，后端重启恢复已有远端 ID 的轮询。提交结果未知时标“待核查”，禁止自动重发造成重复计费。有远端 ID 优先继续查询。文本失败但保留原响应时可“重新校验原响应”，不再次调用模型；真正重提需用户明确确认可能计费。
F11 草稿与版本自动保存输入和编辑，备份可导入；新结果进入素材区，用户主动应用。保存成功提示以实际写入为准；保存失败显示错误并提供备份。不能承诺清理浏览器数据后仍保留前端草稿。
F12 配置与启动通过本地后端启动脚本运行；API 与模型页说明密钥与模型状态。file:// 单 HTML 不直接调用真实 API；后端断开明确报错。密钥不进入项目备份、导出文件或浏览器持久存储。

对象最小字段与关系规则
Project / SKU / Role稳定 ID、类型、名称、revision；SKU / 角色图片与描述；素材来源标记。替换参考图片增加修订号；不改变已经提交任务的输入。新建项目不删除原项目。
ShotID、episode、order、prompt、imagePrompt、motionPrompt、subtitle、duration、role、frameAssetId / frameVersion、frameApproval、activeClipId。镜头排序不靠数组索引作为身份；片段与其实际参考帧绑定。删除角色时需要处理引用或阻止提交。
Task / Attempt任务 ID、项目 ID、类型、模式、快照、依赖、状态；每次尝试记录模型、请求时间、远端 ID、错误及结果引用。提交前持久化意图；获取远端 ID 后立即保存。重试递增 attempt 并保存上一尝试的历史；本地重新校验另记事件而非新模型调用；提交未知不可盲重试。
Asset / Candidate资产 ID、类型、真实来源、原任务与尝试、缓存路径、尺寸 / 时长、创建时间；文本候选保存 baseRevision。生成结果是独立资产。候选应用前比较版本；冲突时先提示，由用户明确确认覆盖或关闭保留。项目不存在时仅下载候选 JSON；不自动覆盖或应用到其他项目。

后端接口约定为 /api/config、/api/status、/api/jobs（提交与查询）及 /api/jobs/{id}/cancel、/retry、/resume、/revalidate、/up（以最终服务实现为准）。配置状态只返回 configured 等必要布尔信息，不回传完整密钥；持久任务记录位于 .runtime/jobs.json，缓存文件经 /api/files/… 访问；供应商原始下载 URL 仅后端保留，不向前端任务接口暴露。

前端负责编辑体验与浏览器草稿；后端是 API 密钥、真实执行状态和远端对账的唯一来源。两者通过任务 ID、项目 ID 和结果引用同步。任务完成且前端离线时，结果先保留在后端缓存，恢复连接后再同步进正确项目。

05 / QUALITY, COST & NON-GOALS

质量取舍、成本提示与实现边界

质量与速度冲突时，最终素材优先商品和角色的关键正确性。预览可以先验证构图，但不降低验收标准冒充成品。商品颜色、形状、标识有关键错误即判不可用；短剧关键角色身份漂移、动作畸变或剧情不符应重做受影响镜头。资源排队和清晰预期优先于追求同时发起大量请求。

真实调用可能产生供应商费用，批量前展示任务数量和云端发送范围，模型名称在API页与任务结果中可见。没有可靠价格与用量数据时不显示虚构费用。取消通常只能停止本地等待、应用结果或后续子任务，无法承诺停止供应商已受理的计算与扣费。

不在本次承诺内边界
全本地真实模型推理API 版已改为百炼云推理。设备配置无需公开；本地承担界面、存储、模板合成和后端代理。
专业修图 / 多轨剪辑只做闭环所需布局、文字、裁切与基础镜头编排；复杂遮罩、调色、转场、配音和口型同步未列为 P0。
自动保证商品 / 角色一致参考图与提示约束降低漂移风险，不能替代人工质量检查。跨 SKU 自动准确改色不作保证。
完整商业账号体系本地单用户工作台；API Key 配置不等于实现了账号、多人权限、订阅和组织授权。
真实任务已验收需求文档不证明 API 成功。真实文本、图像、视频和分集录制链路已经完成有限联调；必须在验收记录中区分这些单例事实与批量成功率、稳定性、内容质量评估。
06 / ACCEPTANCE PLAN

可操作的验收路径

当前可用与仍待验证

证据层级本次实际结果与边界
已完成单例联调真实商品文本方案、参考图编辑和图生视频均跑通；真实 MP4 可由本地缓存读取，并将片段按分镜顺序与字幕录制为 WebM / VP9，16:9 样本为 960×540、无音轨。这证明这些路径可执行，不证明任意素材均有同等效果。
已修复的本地校验一次两集、六镜头分镜响应包含合法空字幕，旧校验器误拒绝。现允许空字幕并用已保留原响应重新校验通过，没有追加供应商 POST；本地校验事件与模型调用次数分开记录。
未完成统计评估未形成多 SKU 保真、角色一致性、动作自然度、批量失败率、长时间并发、费用预测及跨浏览器兼容的充分样本。不能将少量真实成功调用外推为生产可用质量。
  1. 启动与无配置状态。通过本地启动脚本进入；未配置密钥时 AI 按钮显示可理解的阻塞，模板功能正常。浏览器存储和备份不含密钥。
  2. 任意商品。上传三个花瓶 SKU；请求商品方案，预览后应用；分别用模板和真实图片模式制作。核对结果来源、对应关系、尺寸和导出内容。
  3. 异步与编辑。提交批量生成后继续编辑已有画面；结果到达后不覆盖修改。AI 文本请求期间修改输入，返回后出现版本冲突处理。
  4. 短剧依赖。输入故事与角色图，真实拆分镜头；逐步制作拦截未确认的分镜；一键出片无需逐镜确认并按图像依赖生成视频，确认可播放并保存了远端 ID。
  5. 失败与取消。检查错误提示、单项重试、依赖等待。取消后不宣称供应商运算和收费已停止，完成资产仍保留。
  6. 重启与未知提交。后端重启后已有远端 ID 的视频继续查询；提交未知任务进入人工核查状态，不自动重复提交。
  7. 真实缓存。完成文件下载到本地后再展示可用；断网后仍能读取已缓存文件。临时 URL 失效不能使“完成”资产悄然丢失。
  8. 记录证据。逐项写明通过、失败或未执行，保存不含密钥的模型 ID、任务 ID、响应摘要和实际文件；性能与质量未测时明确标注。
