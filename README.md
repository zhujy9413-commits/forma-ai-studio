# Forma 造物 · v2.1 交付修订版

面向图像与视频内容创作者的交互 Demo，包含电商素材和批量短剧两条工作流，以及产品、交互、模型评测和并发任务四份文档。

本版本使用阿里云百炼 API 推理，本机负责界面、任务代理、存储与视频合成。它是可交互、可连接真实模型的 Demo；原测试题的“全本地推理”约束已按项目决定改为 API。

## 启动

需要本机安装 Python 3，并使用支持 Canvas、MediaRecorder 的浏览器。

1. 下载或克隆仓库。
2. 如需真实生成，将 `.env.example` 复制为 `.env`，在本机填写百炼 API Key。密钥、域名与模型权限应属于相同地域。
3. macOS 可双击 `打开工作台.command`；也可在项目目录运行：

   ```sh
   python3 启动工作台.py
   ```

4. 打开 <http://127.0.0.1:18767/forma/>。不填写密钥也可载入配套实测案例、播放缓存素材；新模型请求需要有效配置，并可能产生费用。

不要直接双击 `forma/index.html` 使用真实 API。启动脚本会打开本机工作台；已有服务时复用现有实例。

## 两条工作流

- 电商素材：上传自己的商品与 SKU，选择主图、生活场景及尺寸，批量制作、编辑并导出素材。
- 批量短剧：故事与角色、分镜规划、分镜/视频版本选择、编排和分集导出。可逐步制作，也可一键制作。
- 分镜版本：每镜可看图选择；“查看历史分镜素材”可找回旧项目图片，跨项目导入会保留来源。
- 一键制作：优先复用选定图片；可选择自动采用视频，或保留为候选并自行选择。
- 同集连续续拍：上一段视频完成后提取实际尾帧，再提交下一段。独立镜头仍可使用各自分镜；跨集重新开始。

故事页提供不调用模型的案例入口。“尾帧续镜实测”展示本轮真实两段视频，名称中明确标注动作仍有偏差。

## 模型与本地数据

默认配置为 DeepSeek 文本、`wan2.6-image` 图像、`wan3.0-video` 视频，具体模型 ID 以 `.env.example` 和 API 设置页为准。

- `.env` 保存本人本机配置，不提交到 Git。
- `.runtime/` 保存运行任务、输入与生成缓存，不提交到 Git。
- `实测样例/` 是明确纳入交付的演示图片、视频和不含密钥的调用记录。
- 项目草稿保存在浏览器本机存储中，可导出项目备份。克隆仓库不会恢复原电脑的私有草稿或运行缓存。

## 验证与限制

当前包含 25 项隔离流程检查及有限真实 API 实测记录，详见验收文档。本次新增续镜验证仅调用两次视频 API、零次图像 API；两段原片各 3 秒、1280×720，并通过产品生成了编排预览。

实测中首帧重置和服饰跳变得到改善，但第二镜男子移动仍超过描述，窗面仍有淡反射；不能据此承诺任意故事稳定自动出片、人物一致性或物理关系完全正确。请对结果进行内容检查，必要时只重做受影响镜头。

续镜需要页面保持打开以提取尾帧和提交后镜，本地合成需页面位于前台。失败或提交未知时不自动重复付费请求；取消本地后续不保证撤回供应商已受理的运算与费用。
