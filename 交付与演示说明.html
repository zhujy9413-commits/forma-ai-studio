最快演示入口：启动后选择“批量短剧”，在故事页点击“载入已验证演示案例（不调用模型）”。可直接预览两个真实片段、选择版本与导出成片；原项目保留在“我的项目”。需要生成自己的内容时再替换故事和参考图。

本版存放在“胡泊 / Forma_交付修订版_v2.1”，默认端口18767。原“测试题C-低 / Forma_API版”及18766旧工作台保留。新版已有任务和媒体为本机副本，不会重新调用模型；浏览器项目独立，需要时用项目JSON导入迁移。

  1. 短剧先生成分镜图，点击“检查 / 确认分镜”。检查图像并填写动作、运镜，勾选审核后确认。

  3. 在“视频版本”预览并采用，再进入编排和导出。新版本不自动替换旧片段，生成成功不表示质量通过。

启动工作台

  1. 在本文件所在目录双击 打开工作台.command。需要系统可用的 Python 3，无第三方 Python 包依赖。
  2. 浏览器会打开 http://127.0.0.1:18767/forma/。终端保持打开；结束时按 Control+C。
  3. 若系统阻止双击，在终端切换到本目录后运行 python3 启动工作台.py。
  4. 进入左侧 API，确认配置状态。当前这台电脑的私有 .env 已配置并验证可用。换电脑或使用分享包时，将 .env.example 复制为 .env，填写自己的百炼 Key；也可在 API 页面填写，页面配置仅在服务进程内存保留。
真实 API 功能必须通过启动脚本使用。直接打开 forma/index.html 不能连接本机 API。此 API 版的固定默认端口是 18767；端口改变后浏览器项目存储来源也会改变，换端口前请导出备份。

推荐演示顺序

  1. 电商：输入商品信息，上传每个颜色 SKU 的图片。小花瓶、杯子等均可；示例商品不限制品类。用“AI生成商品方案”提交文本，完成后在任务中心预览、应用。
  2. 批量素材：选择主图或生活场景及尺寸，制作方式选“真实 API 生成”。先用 1 个 SKU × 1 场景 × 1 尺寸检查效果，再扩大批量。任务数按组合相乘，每项图像调用会计费。
  3. 编辑与导出：结果到素材区后进入画布，调整整图位置、缩放、裁切和文字，保存新版本，再导出 PNG / ZIP。生成任务可以继续运行；原图和旧版本保留。
  4. 短剧：输入故事、替换角色图，用“AI拆分分镜”获得候选；预览后应用。修改分集、画面提示词与角色，在真实 API 模式提交分镜图及视频。可选择一键出片自动完成图片、视频、采用与预览；逐步制作路径保留人工确认。
  5. 片段编排：查看 AI 分镜结果并手动应用画面；检查 AI 视频，调整镜头顺序、字幕和时长。每镜有真实视频后，可预览或批量导出剧集。缺片会提示，不自动换成静帧。
  6. 任务恢复：查看真实状态。已有远端视频 ID 时使用“继续查询”；重提会再次调用并需确认。文本因本地字段校验失败且留有原响应时，可“重新校验原响应”，不重发模型。

完整短剧演示可先保留一个 2 秒镜头检查链路，再逐步增加镜头与剧集；每镜生成图像和视频分别计费。无需调用模型的演示可明确切换“本地模板 / 静帧合成”，其进度与资源不足按钮属于本地演示。
