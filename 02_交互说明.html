诊断发现：最近试做项目记录为0张新图片、6段视频，6个请求引用同一张首帧。前三段实际解码均为3秒、1280×720，抽帧可见首帧重置、黑外套变米色、独立窗上人像及动作衔接失败。原有6张分镜图片仍在旧项目ID下，不能当作当前镜头的新版本。当前质量案例判为未通过；新增按钮与接口成功不能代替内容验收。

分镜版本窗口现在明确显示已关联图片数，提供“查看历史分镜素材”。历史库只列图片生成结果，标注原项目及镜头；跨项目必须由用户“导入并选用”，记录来源，不自动按同名认作同一镜头。同项目、同镜头缓存结果可恢复到版本列表，不自动覆盖当前选图。

同场景可在视频版本中“取尾帧续拍下一镜”，本地解码并提取所选片段实际尾帧。选用尾帧本身不调用模型，之后生成视频仍可能计费。一键制作的“镜头衔接”可选择独立分镜或同集连续续拍。连续模式在上一段视频成功保存后读出尾帧，再提交下一段；跨集重新使用独立首帧。后镜独立分镜保留作参考，界面明确禁用其首帧选择，并分别显示复用图、尾帧、新增图片及视频数量。

续拍依赖网页读取尾帧与提交后镜，需保持页面打开。已提交任务由后端持久化；恢复页面后仅在已授权批次内续接尚未提交的计划，已登记任务ID不重复创建。尾帧读取或提交异常时暂停，不自动付费重试。原片段与版本均保留。续拍提示以实际首帧服饰与姿态为准；这不保证人物动作、物理反射或跨镜故事质量，也不是首尾帧模型模式或插帧功能。

25项隔离流程检查通过，其中7项新增覆盖尾帧输入、串行依赖、跨集重启、失败不重复调用、历史手动导入与同镜头缓存恢复。真实两段续镜验证已完成，链路通过与内容偏差分开记录，详见下方结果。

自选分镜版本与一键出片

“03 批量制作”的每个镜头都有“选择分镜版本”，可看图比较并选用；不调用模型。已选版本优先于最新候选，不会因重做图片而自动替换。一键确认窗口也可逐镜换版本、使用自定义图或选择重新生成，并实时计算图片和视频请求数。视频的手动选择与自动采用均可使用；缺片窗口增加“自己选择视频版本”，批量采用只是快捷选项。

当前短剧提供两条路径。在“03 批量制作”点击“一键出片”，确认各镜头使用的分镜版本及调用数量后，复用已选图片、仅补生成缺失图片，并制作视频。默认自动采用并合成当前集预览，也可选择“保留为候选，我自己选择视频版本”。全部剧集的片段均保留，可逐集预览或批量导出。需要控制画面时，使用“仅制作分镜图 → 检查 / 确认分镜 → 用确认分镜生成视频 → 视频版本采用”的逐步路径。单镜头返修仍不自动覆盖已选版本。

一键结果标记为自动初稿，未经过人工质量审核。该入口不会自动重新拆分故事或替换当前分镜表。复用已有分镜时直接固化该图作为视频输入，不创建图片任务；新增分镜与视频按后端 depends_on 关联，视频使用本批次图片结果；已提交任务在后端持久保存。恢复页面只查询，不自动补发或重提模型请求。生成期间的编辑冲突会保留结果、阻止自动覆盖；失败、未知提交、取消时下游等待并显示异常，需要用户核查。

合成使用浏览器本地编码，需保持页面打开并位于前台。预览失败保留原片段，不自动重复编码；用户可再次点击预览。全部提交前关闭页面会留下未完整提交状态，必须到任务中心核查。停止本批次会停止本地后续及自动采用，不保证撤回供应商运算或费用。

导出前如果缺片，现在显示具体镜头与匹配情况。已有匹配视频时可批量采用并预览，不调用模型；没有匹配视频时不会将分镜图冒充真实视频，提供制作入口和无调用的已验证案例入口。

增量实测已完成：1张修订图、2段3秒视频，审核、主动采用与成片导出通过本次样例检查；生成质量的结论仅适用于该样例。完整记录见模型评测报告与验收记录。

V2.1 / CURRENT INTERACTION

修订后的短剧操作路径

  1. 故事页补充“全片导演约束”，分镜规划页保留逐镜画面描述。文本模型新响应可带 imagePrompt / motionPrompt；旧响应仍可使用。
  2. 逐步制作时，进入批量制作先只生成分镜图；“重做分镜图”同样只重做图片。
  3. 每镜点击“检查 / 确认分镜”：查看当前画面、选择AI图片版本，填写首帧构图和动作/运镜；复杂反射镜头出现检查提示。勾选人工检查项后“确认分镜（不调用模型）”。“仅保存描述”不等于确认。
  4. 单镜头使用“生成此镜视频 / 仅重做视频”，在弹窗再次核对首帧、动作、秒数和比例，再确认创建1个视频。批量入口“用已确认分镜生成视频”会先检查所有确认，再展示视频请求数量和计费提示。
  5. 完成后进入“视频版本”，逐段播放，点击“采用此视频版本”；逐步制作与单镜返修的新片段不会自动替换已选版本；一键出片按用户选择自动采用或保留本批次结果为候选。旧结果可继续下载。
  6. 编排字幕、时长与镜头顺序，预览及导出本集或全部剧集。未采用片段、缺缓存或描述已变更时给出错误提示。

审核确认是前端产品步骤，不是后端对内容质量的证明。用户仍需检查动作逻辑与角色一致性。当前单镜头生视频模式使用一张已确认首帧；自动提取上一镜尾帧、首尾帧模式和复杂转场尚未实现。

新旧版本使用不同端口，浏览器项目存储分别独立。需要迁移时先在旧版导出项目JSON，再在新版导入；新版私有运行目录保留已有媒体副本。导入会替换新版当前工作空间，操作前应备份。

本版交互以真实 API 的可用状态为准。

本文已对照当前 server.py、forma/api.js 与 app.js，覆盖五步工作流、画布、任务中心、项目、素材与 API与模型设置。真实文本、图片、视频单例调用及真实片段分集录制已联调；表内同时标出当前限制。真实内容质量和批量稳定性仍须通过专门评测，不能由界面状态推定。

用户已授权云端升级，本版不再满足原测试题的全本地推理限制。AI 模式会将输入及参考图发送至百炼；本地模板与静帧运镜必须另行标注。

02 / COMMERCE

电商素材逐页交互

步骤 / 控件触发、输入与反馈校验与结果规则
01 商品与素材商品名称、创作简报；“上传商品图片”、SKU 名称、“替换”、移除按钮。上传后新增卡片，显示原图及来源。本地上传接受 PNG / JPEG / WebP，单图上限 20 MB、长边缩至 1600。发往图片 API 前另转白底 JPEG（透明区填白）；原始上传素材保留。后端也校验媒体格式与请求输入，不能把本地上传规则等同于所有供应商上限。无 SKU 时阻止图片制作。
新增 AI生成商品方案读取当前名称和简报，点击后作为真实文本任务入队；候选弹窗显示标题、副标题、场景提示与注意事项，卖点字段保留于结构化结果。后端未连接、无 Key 或输入为空时不提交。失败保留输入。候选先预览，可应用或关闭；应用时检查提交修订号。候选弹窗不提供逐字段直接编辑，应用后再在项目中调整。
02 素材方案“纯净主图”“日光居所”“自然编辑”多选；尺寸 1:1 / 3:4 / 9:16 / 16:9。v2.1统一API参数，取消无效快慢档位。至少一种场景和尺寸。展示 SKU × 场景 × 尺寸总数。当前不提供速度/质量档位，展示真实统一参数说明。
新增 制作方式选择“百炼 AI 编辑”或“本地模板合成”，说明输入发送范围和使用模型。无配置不能选择后静默执行模板并标成 AI。模板不需要云密钥；用户可以主动切换。预计费用未知时只展示调用数和计费提示。
03 提交批量制作原按钮“提交批量制作”提交当前组合；显示已入队数量。结果按单项完成逐步进入图库，可查看全部 / 主图 / 场景图。提交保存不可变快照；同一操作重复点击不产生重复批次。任务来源与状态持久化。成功必须有实际结果文件，不以返回任务 ID 等同完成。
结果卡片显示缩略图、标题、比例、来源；勾选、编辑、导出、重做。来源至少区分百炼 AI、模板合成、预置示例、编辑版本。重做新建尝试保留原结果；导出读取当前结果，不用旧参考图替代。
04 画布编辑选择素材缩略图；拖动商品；画面尺寸、背景场景、主副标题、缩放、中心裁切、标题位置、背景色与文字色；“保存为新版本”。模板结果支持分层原图布局。AI 返回为整图时，按整图编辑边界提示，不能假称商品已独立抠图；切尺寸或编辑后仍保留 AI 成图内容。
05 导出交付“导出素材包 ZIP”“导出项目备份”“导入项目备份”；未勾选时导出当前项目全部素材。ZIP 包含真实 PNG 和素材清单。模型输出与导出尺寸区分记录；备份排除 Key。导入替换当前工作空间前给明确提示，建议先备份。
通用商品验收

新建项目后上传三个花瓶颜色的原图，分别命名 SKU；批量结果、单张画布、PNG 和 ZIP 都应对应这些新图片。预置保温杯只用于开箱演示。

03 / SHORT DRAMA

批量短剧逐页交互

步骤 / 控件触发、输入与反馈校验与结果规则
01 故事与角色编辑故事或分集脚本、角色名称与描述，替换角色参考图；“规划分镜”。角色与图片稳定 ID 绑定；替换角色图时同步更新绑定该角色的分镜参考图，后续批量任务因此读取新图。角色引用有效才允许提交；预置关键帧不能标成新 AI 结果。
新增 AI拆分分镜以故事及角色档案请求 DeepSeek；返回镜头标题、剧集、画面描述、角色、字幕、时长候选；弹窗预览后应用。结果需结构校验：1–24 镜，标题与画面描述非空，字幕允许空字符串，角色必须有效；当前服务将剧集归到 1–12、时长归到 2–10 秒。请求期间修改了故事或角色，则应用前提示版本冲突。
02 分镜规划原“按段落拆分”“添加镜头”、比例、逐镜画面描述、剧集与角色；AI 成功后可用“查看最近 AI 方案”重新查看候选。“按段落拆分”标注本地规则，替换当前表前确认；不叫 AI 拆分。AI 候选应用也不删除原生成素材。
03 仅制作分镜图只提交图片任务；单镜“重做分镜图”同样只生成图片。结果保留为候选，在“检查 / 确认分镜”中选择并审核。不自动创建视频；从任务结果可“选为候选分镜”，随后仍需人工勾选检查并确认。确认、生成完成与应用分别处理。
03 用已确认分镜生成视频检查所有镜头的确认是否有效，再展示视频请求数与计费确认。只提交视频，不重做分镜图。视频输入固化已确认首帧，记录来源素材ID；旧的后端依赖能力继续用于历史任务。单镜可使用“生成此镜视频 / 仅重做视频”。
单镜“重做分镜图”或“仅重做视频”仅对受影响镜头创建新尝试，其余镜头和成品保留。已有视频与原图绑定不变；采用新图后视频标记需重做，不静默覆盖旧资产。重试输入保持可追溯。
04 编排编辑缩略图选择镜头；标题、字幕、字幕位置、时长、画面比例；“前移”“后移”“替换镜头图片”“预览本集”。真实视频用视频控件预览，不能只显示封面。字幕与时长变化不等于远端原片已重新生成。真实模式本地按镜头顺序录制已有视频并绘制字幕，使用编辑时长与源片时长较小者；不自动补帧或延长生成内容。
05 导出交付选择剧集；原“预览本集”“导出本集视频”“批量导出全部剧集”“导出分镜包 ZIP”“导出项目备份”。真实 API 模式检查每个镜头已采用的 AI 视频后编排录制；缺片时提示先生成或主动改为静帧模式，绝不自动用静帧补齐。原始 MP4 可单独下载；分集录制格式由浏览器支持决定。

视频两种模式必须明确区分

百炼图生视频

使用完成分镜图发起 wan3.0-video；显示异步远端任务状态，实际视频就绪后播放与下载。分集输出通过浏览器逐镜播放真实片段、绘制字幕并实时录制，已实测 WebM / VP9、960×540、无音轨。原始片段仍为供应商 MP4；录制不是无损拼接。

本地静帧运镜

浏览器将图片做缩放运镜并绘制字幕；不是生成式动作视频。需要浏览器编码支持，编码期间保持页面前台；不支持时保留分镜包导出。

点击生成正在请求，可继续编辑或关闭候选区。保存项目 ID、输入快照、提交 revision 和任务 ID；相同 ID 的后端重投幂等。当前文本按钮可主动创建多项独立请求，每项可能计费，不承诺对不同 ID 自动去重。请求失败不丢输入。
生成成功商品方案或分镜表预览，“应用此方案”或关闭；已有候选可从“查看最近 AI 方案”进入。原项目未加载时，只显示“下载方案 JSON”。结构校验后展示，不自动写回项目。关闭只放弃应用，不声称供应商任务已撤销或退费。
点击应用，版本相同更新目标字段，显示应用完成。商品方案写入 aiPlan 供后续图片文案与提示使用；分镜应用前保存旧分镜版本，再替换当前表并增加 revision，触发草稿保存；原素材、任务和已有结果保留。
点击应用，版本不同“提交后项目已有修改”；主按钮改为“检查后确认覆盖当前方案”，用户也可直接关闭。只有用户明确点击确认覆盖后才应用；关闭保留现有方案。原项目不存在时不能将候选应用到当前其他项目，只允许下载 JSON；重新生成属于新调用，可能计费。
输出非法 / 请求失败显示具体问题与重试入口；认证、配额、网络、结构错误分别说明。不把本地拼接内容包装成成功响应。若存在原始响应，任务中心提供“重新校验原响应”，仅运行本地 JSON / 字段校验，无新模型 POST；缺 Key 直接引导设置，重新提交则提示可能计费。
05 / TASK STATES

真实队列的可见状态与动作

任务中心保留全部任务、正在制作、等待执行、需要处理统计。真实任务行显示后端状态及阶段，并根据状态提供“上移”“查看结果”“继续查询”“重新校验原响应”“重提（可能计费）”“取消本地后续”。真实任务不提供模拟供应商失败；本地演示动作与真实 API 分开。

状态界面说明 / 可用动作恢复及计费边界
排队 / 等待依赖显示等待原因与前置任务；允许上移和取消。未提交供应商的任务取消可阻止调用。上移不越过依赖，也不抢占已运行任务。
提交中显示正在向服务商提交；不展示虚构完成率。网络异常可能导致是否受理未知；不能简单标失败后自动重发。
远端运行 / 轮询显示服务端状态、已等待时间、可查看远端任务 ID。保存远端 ID；刷新页面不重复提交。后端重启后继续查询已有 ID。
缓存结果“生成完成，正在保存结果”。先下载并检查文件，再标可用。视频有远端 ID 时可继续查询并下载；同步图像当前无独立重下入口，重提可能再次生成并计费。
已完成预览、下载、编辑或应用；显示模型与来源。完成文件已本地缓存；不能仅因有远端 URL 或成功提交就进入此状态。
失败展示可理解的错误；可处理后重新尝试，其他任务继续。认证和参数错误不自动重试；存在 raw_text 的失败文本可点击“重新校验原响应”，成功后标记为“原始响应重新校验通过，未再次调用模型”。服务查询恢复与重新生成分开；重提仅作用当前项。
提交未知 / 待核查显示“请求可能已受理，请先核查远端状态”；无自动重发。保留提交时间与请求摘要；界面“重提（可能计费）”打开确认弹窗，用户核查后才能点击“已核查，确认重新提交”。有远端 ID 时改用“继续查询”，不重新 create。当前界面不提供手动录入未知远端 ID 的入口。
已取消 / 已中断保留输入与已完成结果，停止后续依赖，展示取消含义。不能承诺停止服务商计算或扣费。远端任务未确认停止时仍保留 ID，继续必要对账；不丢弃已产生结果。

API与模型页可选总并发 1 或 2；硬上限为总计 2 项、图片 1 项、视频 1 项，文本也占总预算。界面展示真实状态，不再以旧设备模拟状态决定真实 API 并发。更完整状态机、对账和幂等规则见 多并发任务说明。

06 / API & MODELS

API与模型设置页

控件 / 信息要求异常反馈
后端连接显示本地服务连通状态；提供启动脚本说明。页面通过 HTTP 本地后端使用真实 API；媒体只经 /api/files/ 本地缓存读取，不向前端暴露供应商原始下载 URL。后端未启动时说明如何启动；file:// 页面不直接向百炼发送密钥和请求。
API Key 配置“百炼 API Key”密码输入，点击“保存本次配置”后写入后端内存并清空输入；留空保留当前密钥。根目录私有 .env 可用于重启恢复；“重新读取 .env”触发后端配置重读。空值或服务拒绝时明确提示；完整密钥不写 IDB、localStorage、项目 JSON、导出包或日志。私有配置不随交付打包。
模型配置可编辑 API Host、文本模型、图像模型、视频模型，以及 API 总并发；默认文本 deepseek-v4-pro、图像 wan2.6-image、视频 wan3.0-video。Host 与 Key、模型必须匹配地域。模型不可访问、无权限、额度不足或参数不支持时展示真实错误，不用静态绿色可用替代调用验证。
连通 / 配置检查“测试文本连接（调用一次）”提交一次真实文本任务，并进入任务中心；“导出真实调用日志”导出后端记录。配置存在不代表任意模型均已获权。文本测试可能产生费用；单个模型成功不证明另外两个可用。日志区分供应商 POST 次数和本地重校验等终态事件，不能把事件数当成付费调用数。
数据发送范围说明文本、商品图、角色图与分镜图会按任务发送至百炼，结果缓存于本机。不能继续显示“所有素材仅在本地、所有推理本地完成”。模板模式可单独说明本地处理。
07 / SAVING, EXPORT & ERRORS

保存反馈、兼容与空状态

场景交互规则
编辑保存输入后显示“正在保存”；实际 IndexedDB 写入完成才显示“已保存到本地”。当前约 400 毫秒合并调度，不承诺 400 毫秒内持久化完成；最后尚未写入的输入不能承诺零丢失。
存储失败显示保存异常与原因，保留当前页面内容，提供项目备份。清理浏览器数据、无痕会话和配额问题明确属于前端草稿边界。
刷新与重启刷新恢复项目与编辑；真实任务向后端 /api/jobs 对账，不把远端运行任务误标为本地中断后立即重发。后端重启恢复远端 ID 查询，未知提交等待人工核查。
空项目 / 空结果显示上传商品或输入故事的具体行动；无结果不能导出空包并提示成功。无镜头时引导拆分或添加镜头。
上传失败提示允许格式和容量；读取失败保留已有素材，失败文件不生成空卡片。真实 API 素材规范与浏览器上传规则分别校验。
导出兼容实际生成的文件可读取、解码或播放后交付。浏览器不支持静帧编码时提示更换支持环境或导出分镜包；不把失败写成已导出。
项目备份恢复导入当前工作空间的替换影响先说明；校验文件类型和结构，成功后恢复关联。导出排除所有认证信息，任务记录不能触发远端重复提交。
